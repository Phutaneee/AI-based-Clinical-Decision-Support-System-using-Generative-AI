# AI-based-Clinical-Decision-Support-System-using-Generative-AI


## Overview
An AI-powered clinical decision support system that uses Large Language Models (LLMs) and Retrieval-Augmented Generation (RAG) to analyze user-provided symptoms and generate context-aware medical insights using relevant medical knowledge sources.

## Key Features
- Natural language-based symptom analysis.
- RAG-based medical information retrieval.
- LLM-powered contextual response generation.
- Semantic search using vector embeddings.
- Explainable responses with medical disclaimers.

## Technology Stack
- **Language:** Python
- **GenAI:** LLMs, Prompt Engineering
- **Framework:** LangChain
- **Vector Database:** ChromaDB
- **Embeddings:** Hugging Face
- **Interface:** Streamlit

## Workflow
User Input → Symptom Processing → Medical Knowledge Retrieval → Context Augmentation → LLM Response Generation.

## Disclaimer
Designed for preliminary medical information assistance, not for diagnosis or replacement of professional medical advice.
